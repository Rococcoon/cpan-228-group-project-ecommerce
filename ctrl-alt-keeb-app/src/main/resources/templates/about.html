About the Project

About Ctrl-Alt-Keeb

Ctrl-Alt-Keeb is an e-commerce inventory application for custom split keyboards and mechanical keyboard parts.

Project Purpose

The application provides a clean interface for browsing and managing a collection of mechanical keyboards.

Users can view product information, filter keyboards by layout and key count, sort results and open detailed product pages.

New keyboards can also be submitted through a validated form and saved to the application database.

Main Features

  • Product catalogue
  • Search and filtering
  • Server-side sorting and pagination
  • Validated product form
  • Database persistence with Spring Data JPA

Technology Used

The application uses a modern Spring Boot web-development stack.

Java 21
Spring Boot
Thymeleaf
Bootstrap
Spring Data JPA
